Read this file, `README.md`, and `test/README.md` before changing anything.

Run commands inside the toolchain: `devenv shell --quiet -- <command>`. `check` runs the unit tests and lint, and it must pass before a commit.

Ask before you:

- change what `install.sh` does, except to fix a failure a test shows, in its own commit that names the failure;
- loosen or remove a test assertion;
- add a document to the repository root, which holds `README.md`, `AGENTS.md`, `CLAUDE.md`, `REPORT.md`, and `LICENSE`.
